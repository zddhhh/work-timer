# Windows 安全说明（误报处理）

安装包和 `WorkTimer.exe` 目前没有数字签名，程序主体由 PyInstaller 打包。部分杀毒软件可能按「未知发布者 + Python 运行库 + 安装行为」做启发式拦截。

## 用户遇到拦截时

只从项目 Release 页下载，并核对 Release 说明里的 SHA-256。确认哈希一致后，可在杀毒软件的隔离区恢复并添加信任；不要关闭整机防护。

Windows Defender：打开 **Windows 安全中心** → **保护历史记录**，找到对应文件后选择允许或还原。

360 等第三方杀毒软件：先核对文件来源和 SHA-256，再从隔离区恢复。也可以把误报文件提交给厂商复核。

根治方案是用受信任的代码签名证书给安装包、启动器和程序主体签名。未签名前只能降低启发式特征，不能承诺所有杀毒软件都不误报。

## 1.3.35 起为降低误报做的改动

- 改发安装包（Inno Setup），程序装成普通文件夹，不再是每次启动往临时目录解压一整套 Python 的单文件 exe
- PyInstaller 启动器（bootloader）自己编译，不再用被大量恶意样本复用的官方预编译件；不加 UPX 壳
- exe 带完整版本信息（产品名、公司、版本号）
- 安装包不用 LZMA 固实高压缩，改用普通 ZIP 非固实压缩，降低高熵壳特征
- 更新改为静默运行新版安装包，不再「复制自身到临时目录 + 隐藏窗口进程替换 exe」；卸载走 Inno 自带卸载程序，不再用隐藏的 cmd 延时删文件
- 按键隐藏不再每帧扫描全键盘按键状态（容易被判成键盘记录），改为只看隐藏键本身和系统「最后一次输入」时间

## 三、奇安信天擎报 PowerShell 可疑脚本

`1.0.86` 起更新和桌面快捷方式都不再调用 PowerShell。若仍提示，点「允许本次操作」或把 `WorkTimer.exe` 所在目录加信任；从旧版升到 1.0.86 的那一次可能仍会弹（旧程序还在用 PowerShell 换文件），装上之后再更新不应再弹。

## 四、开机自启动被拦

`1.0.88` 起改为在「启动」文件夹放快捷方式，不再写 `Run` 注册表。若仍提示，把 `WorkTimer.exe` 加到天擎信任即可；未签名软件改启动项无法从根上骗过所有安全软件。
